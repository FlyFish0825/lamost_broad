# LAMOST 外接板（Broad Board）

LAMOST（Large Sky Area Multi-Object Fiber Spectroscopic Telescope）光谱巡天望远镜外接板项目。本项目包含一块约 **1.3 米**的大尺寸基板（机械背板），以及安装在其上的 **52 块小单元 PCB**。每块小单元 PCB 搭载一片 STM32F302 MCU。系统采用两级 CAN 结构：26 个主节点，每个主节点下挂两块外接板、共 32 个单元接口。外接板传递 CAN 接线，MCU 仅静默监听指定单元的亮灯指令，通过端口旁 LED 辅助现场插拔定位。

## 项目概览

| 类别 | 说明 |
|------|------|
| **主控芯片** | STM32F302x8（Cortex-M4, 72MHz），每块小单元 PCB 一片 |
| **通信方式** | CAN 2.0，250kbps；26 组下行总线，外接板仅静默监听 |
| **晶振** | 24MHz 外部晶振 |
| **基板尺寸** | ≈1.3m，中间方形倒角，走线孔直径 50mm，中间孔 150mm |
| **小单元 PCB** | 共 52 块，每块搭载 STM32F302 + CAN 收发器，16 通道输出 |
| **PCB 层数** | 2 层板（小单元 PCB） |
| **设计工具** | 立创EDA / EasyEDA (PCB), SolidWorks (3D 结构) |
| **开发周期** | 2026.03 — 至今 |
| **作者** | dushiyu ([FlyFish0825](https://github.com/FlyFish0825)) |

## 系统架构

```text
上级 CAN
  ├─ 主节点 M01 ─ 独立下行 CAN ─ 两块 PCB ─ 本组单元 ID 1～32
  ├─ 主节点 M02 ─ 独立下行 CAN ─ 两块 PCB ─ 本组单元 ID 1～32
  ├─ ……
  └─ 主节点 M26 ─ 独立下行 CAN ─ 两块 PCB ─ 本组单元 ID 1～32
```

- **主节点**：布局图中的 26 个正方形模块，每个主节点对应两块外接 PCB。
- **外接 PCB**：共 52 块，每块 16 个端口，每个端口连接一个单元。PCB 全局编号用于物理位置和端口映射，不是组内单元 CAN ID。
- **单元 ID**：每个主节点下独立使用 1～32，不同主节点之间重复使用这些编号。端口与组内单元 ID 的对应按实际配置确认，不能仅凭 PCB 编号推断。
- **静默监听**：外接板 MCU 监听 CAN 指示命令并控制本地 LED，不发送数据帧、应答或心跳，不做软件转发，也不参与 CAN ACK 或错误标志发送。
- **物理分组**：以 `Canvas/main_node_pcb_groups.json` 和 `just外接板/picture/主节点布局.png` 为依据。JSON 的历史字段 `local_can_id=0/1` 仅保留为两块板的排序索引，不代表实际 CAN 地址。

## 硬件架构详解

### 基板（外接板基板）—— 机械背板

基板是一块约 **1.3 米**的大型机械背板，用于承载 52 块小单元 PCB 并提供互联走线：

- **尺寸**：约 1.3m，中间为方形倒角设计
- **材质**：金属/绝缘基材
- **走线孔**：多个直径 Φ50mm 的走线孔，用于线缆穿绕
- **中心孔**：中间开 Φ150mm 大直径孔
- **对位孔**：含中心对位圆柱孔，用于 PCB 安装定位
- **挖空区域**：特定区域镂空/挖空处理
- **基板布线**：基板上绘制 CAN 总线（统一在右侧走线）和电源总线，连接各 PCB
- **电源接口**：电源接口位于基板背面

基板 3D 模型文件：
- `just外接板/外接板基板.SLDPRT` / `外接板基板.STEP` — SolidWorks 零件及通用格式
- `just外接板/基板2.STL` — 3D 打印格式（约 31MB）
- `just外接板/布线.SLDPRT` / `布线.STL` — 基板布线模型（约 19MB）

### 小单元 PCB —— 52 块（搭载 STM32）

每块小单元 PCB 是一款独立的两层电路板，搭载完整的 MCU 系统，安装在基板之上：

| 参数 | 说明 |
|------|------|
| **数量** | 共 52 块 |
| **MCU** | STM32F302x8（Cortex-M4, 72MHz），每块一片 |
| **通道数** | 每块 16 个通道/端口 |
| **总端口** | 52 × 16 = 832 个 |
| **层数** | 2 层板 |
| **晶振** | 24MHz 外部晶振 |
| **CAN 收发器** | 外接 CAN 收发芯片，接入基板上的 CAN 总线 |
| **电源方案** | 5V → 3.3V，功率电感降压，钽电容滤波 |
| **终端电阻** | 120Ω CAN 终端匹配电阻，开关控制（位于总线两端节点） |
| **LED 指示** | TIM1 软件 PWM，当前约25%占空比 |
| **调试接口** | SWD 调试/下载接口 |
| **复位** | Boot0 复位电路 |
| **网络拓扑** | 26 个主节点，每组两块外接 PCB，MCU 仅静默监听 |

> 52 块 PCB 使用外接板固件工程（`lamost_broad_MCU/`），`PCB_ID` 用于选择本板端口映射。主节点程序与外接板监听逻辑是不同职责。MCU 已配置 SILENT 模式并接入定位指令处理框架；正式报文格式与端口到组内单元 ID 的对应仍待提供。

小单元 PCB 参考设计（`小单元原理图设计+PCB.zip`）包含：
- 原理图（PDF）
- PCB 布局图（PDF + 仿真顶层/底层图）
- SMT 3D 渲染图（含标注）
- 实物照片（顶层/底层）
- 主体尺寸图
- 设计说明文档（docx）

### 分块插线板

用于连接各小单元 PCB 的接口模块（16 通道），3D 模型文件：
- `分块插线板_16.STEP` — 标准间距版本
- `分块插线板_16接头间距加大.STEP` — 加大接头间距版本

## 固件功能

固件工程 `lamost_broad_MCU/` 基于 STM32CubeMX + HAL 库，使用 CMake 构建，烧录至每一块小单元 PCB 上运行。

详细的板号配置、十进制开机显示、CAN 指令框架和测试方法见 [MCU 固件详细说明](lamost_broad_MCU/readme.md)。

### 主要功能模块

| 模块 | 说明 |
|------|------|
| **CAN 接收** | 250kbps、SILENT 模式，FIFO0 中断入队，主循环调用 `CAN_Command_Process()`；示例协议默认关闭 |
| **LED 控制** | TIM1 软件 PWM（100Hz、约25%占空比），`just_led.c/h` 实现 |
| **DMA** | USART1 RX/TX DMA 已配置；CAN 接收通过中断处理 |
| **UART** | printf 重定向，调试打印输出 |
| **TIM** | 定时器用于 PWM 生成和时序控制 |
| **GPIO** | 通用 IO 控制，CAN 引脚复用配置 |
| **中断** | CAN FIFO0 中断接收，接收值存储与处理 |
| **端口映射** | `pcb_map[16]` 保留全局焦面映射；定位使用独立的 `CAN_COMMAND_PORT_UNIT_IDS` 组内单元表 |

### 开机板号与定位指令框架

在 `lamost_broad_MCU` 目录下配置板号，例如 PCB23：

```bash
cmake --preset Debug -DPCB_ID=23
cmake --build --preset Debug
```

`PCB_ID` 的合法范围为 1～52，未指定时沿用 PCB1。上电按十进制分两次显示板号：**十位亮 2 秒 → 全灭 1 秒 → 个位亮 2 秒**。数字 1～9 分别对应 LED1～LED9，数字 0 对应 LED10，其余 LED 熄灭。例如 PCB23 先亮 LED2，再亮 LED3；PCB7 显示为 07，先亮 LED10，再亮 LED7；PCB10 先亮 LED1，再亮 LED10。相同数字（如 PCB11）也会被中间 1 秒的熄灯分隔。5 秒计时不阻塞 CAN 接收；没有定位指令时随后全灭。若期间收到合法定位指令，则显示结束后应用最后一条指令。

新增逻辑集中在 `Core/pcb_broad/can_command.c/.h`，沿用原接收缓存与定时器 LED 驱动：

- `CAN_Command_Decode()`：协议识别与字段提取的替换入口。正式协议未知时默认忽略报文，避免误亮灯。
- `CAN_COMMAND_PORT_UNIT_IDS`：本板 16 个物理端口对应的组内单元 ID，取值 1～32，0 表示未配置。默认全0，不能用全局焦面 A 编号替代，也不会自动推断两块板各自的 ID 范围。
- `CAN_Command_Process()`：合法新目标在本板则点亮对应端口；在另一块板则清除本板旧指示。无关或非法报文不改变已有指示。
- `CAN_Command_Poll()`：结束 5 秒板号显示。诊断计数保存在 `can_command_status`，仅供调试器观察，不经 CAN 发送。

台架示例协议通过 `-DCAN_COMMAND_EXAMPLE_ENABLE=ON` 显式启用，**不是已确认的实际协议**。还需填写本板正确的端口单元表才能定位亮灯：标准数据帧 `ID=0x6F0`、`DLC=4`，`4C 44 01 nn` 定位单元 nn（1～32），`4C 44 00 00` 取消定位。正式协议确定后替换解析入口，不把该示例直接当成现场协议。

主机回归测试可从仓库根目录运行 `python lamost_broad_MCU/tests/run_can_command_tests.py`，需要本机 GCC；测试使用 HAL 替身，不连接硬件。

### 关键引脚映射

| 功能 | 引脚 | 说明 |
|------|------|------|
| CAN TX | PA12 | GPIO_AF9_CAN 复用 |
| CAN RX | PA11 | GPIO_AF9_CAN 复用 |
| LED1～LED9 | PA0～PA8 | GPIO 指示输出 |
| LED10～LED16 | PB0、PA15、PB3～PB7 | GPIO 指示输出 |

### CAN 总线参数

- **波特率**：250 kbps
- **主频**：72MHz（24MHz 晶振 × PLL）
- **终端电阻**：120Ω，总线两端节点含开关控制（可切换），带丝印标注
- **CAN 接口**：CANH / CANL 配对（丝印方向已修正）
- **拓扑**：26 个主节点分别连接本组下行 CAN；每组两块外接板，单元 ID 1～32 在各组重复使用
- **Filter**：当前配置为全部接收（不过滤）

## 接口映射可视化工具

[Canvas/canvas_assembly.html](Canvas/canvas_assembly.html) 是唯一保留的页面入口。页面自包含，无需联网或安装依赖，直接用浏览器打开即可。

### 功能与数据

- **装配总览与两板 3D**：查看焦面、理线板、铝基板、支撑结构和光纤路径；默认相邻平面间距 420 mm。
- **2D 布线**：编辑焦面 A → 理线 L → PCB/端口映射，支持定位、连续连接、撤销和恢复当前层。
- **CAN 分组**：标注 M01～M26、PCB1～PCB52，沿用主节点布局图配色，支持点击分组、放大和平移。板位 1/2 仅表示组内 PCB 顺序。
- **基准点**：88 个 Inner 对应已有焦面单元，36 个 Outer 为外围参考点；统一使用与普通节点同尺寸的橙色圆环。
- **数据规模**：726 个焦面单元、742 个理线孔位（含 16 个备用孔）、52×16=832 个 PCB 端口；726 个端口已映射、106 个保留。
- **显示比例**：焦面 Ø570 mm、中心孔 R40；铝基板约 Ø1300 mm。理线板尺寸与板厚、支撑结构为参考图示意，不作为加工尺寸。原始映射坐标和端口顺序保持独立。
- **性能**：默认透明视图按完整光纤路径绘制，缓存几何与端口索引，使用按帧刷新调度；实体板件模式使用 WebGL2 深度检测与批量绘制，正确处理板面、节点和孔洞遮挡；不可用时回退到透视查看。高分屏按实际像素比例绘制。
- **保存与导出**：支持映射 JSON 导入/保存和 PNG 视图导出。浏览器保存文件包含 `fronts/routes/pcbs`，不等同于目录中的两个 `optimized_*.json`。

### 映射与固件表同步

```bash
python Canvas/opt_front_to_middle.py
```

脚本读取 `canvas_assembly.html` 的内置默认映射，完成全部校验后同步两个映射 JSON、主节点分组的端口明细、页面的分组摘要，以及 `lamost_broad_MCU/Core/pcb_broad/just_led.c` 的 52 张端口表。它不会重新优化走线，也不会读取浏览器中尚未写回页面的编辑。

历史后端 JSON 的 `A` 键仅为顺序索引，真实端点以 `middleId/frontId` 字段为准。两个 Excel 是坐标参考数据，修改后不会自动更新页面内置坐标。

旧 `canvas.html` 已从当前目录移除，历史版本可通过 Git 提交 `bb9f067` 找回。

## 快速开始

### 固件编译与烧录

```bash
cd lamost_broad_MCU
cmake --preset Debug
cmake --build build/Debug
# 使用 ST-Link / J-Link 逐块烧录至 52 块小单元 PCB
```

或使用 STM32CubeMX 打开 `lamost_broad_MCU.ioc` 进行配置和代码生成。

### 查看基板设计

使用立创EDA 或 EasyEDA 打开 `外接板20260402.eprj` 工程文件。

### 查看 3D 模型

- **SolidWorks**：打开 `just外接板/` 中的 `.SLDPRT` 文件或 `pcb_3d_model/3D_PCB2_2026-04-02.SLDASM` 装配体
- **通用查看器**：任意 STEP/STL 查看器可打开 `.step` / `.stl` 文件

### 接口映射编辑器

直接用浏览器打开 `Canvas/canvas_assembly.html`。
