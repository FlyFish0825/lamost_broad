# LAMOST 外接板（Broad Board）

LAMOST（Large Sky Area Multi-Object Fiber Spectroscopic Telescope）光谱巡天望远镜外接板项目。本项目包含一块约 **1.3 米**的大尺寸基板（机械背板），以及安装在其上的 **56 块小单元 PCB**。每块小单元 PCB 搭载一片 STM32F302 MCU，各 PCB 之间通过基板上的 CAN 总线互联通信，用于光纤光谱仪的信号中继与分配。

## 项目概览

| 类别 | 说明 |
|------|------|
| **主控芯片** | STM32F302x8（Cortex-M4, 72MHz），每块小单元 PCB 一片 |
| **通信方式** | CAN 2.0, 250kbps，CAN 总线绘制在基板上，56 节点多主网络 |
| **晶振** | 24MHz 外部晶振 |
| **基板尺寸** | ≈1.3m，中间方形倒角，走线孔直径 50mm，中间孔 150mm |
| **小单元 PCB** | 共 56 块，每块搭载 STM32F302 + CAN 收发器，16 通道输出 |
| **PCB 层数** | 2 层板（小单元 PCB） |
| **设计工具** | 立创EDA / EasyEDA (PCB), SolidWorks (3D 结构) |
| **开发周期** | 2026.03 — 至今 |
| **作者** | dushiyu ([FlyFish0825](https://github.com/FlyFish0825)) |

- **基板（外接板基板）**：大型机械背板，上面绘制 CAN 总线和电源线，开有走线孔和中心孔，56 块小单元 PCB 安装固定其上

- **CAN 总线**：在基板上走线，连接所有 56 块 PCB，总线两端含开关控制的 120Ω 终端电阻

## 硬件架构详解

### 基板（外接板基板）—— 机械背板

基板是一块约 **1.3 米**的大型机械背板，用于承载 56 块小单元 PCB 并提供互联走线：

- **尺寸**：约 1.3m，中间为方形倒角设计
- **材质**：金属/绝缘基材
- **走线孔**：多个直径 Φ50mm 的走线孔，用于线缆穿绕
- **中心孔**：中间开 Φ150mm 大直径孔
- **对位孔**：含中心对位圆柱孔，用于 PCB 安装定位
- **挖空区域**：特定区域镂空/挖空处理
- **基板布线**：基板上绘制 CAN 总线（统一在右侧走线）和电源总线，连接各 PCB
- **电源接口**：电源接口位于基板背面

基板 3D 模型文件：
- `just外接板/外接板基板.SLDPRT` / `外接板基板.STEP` — SolidWorks 零件及通用格式
- `just外接板/基板2.STL` — 3D 打印格式（约 31MB）
- `just外接板/布线.SLDPRT` / `布线.STL` — 基板布线模型（约 19MB）

### 小单元 PCB —— 56 块（搭载 STM32）

每块小单元 PCB 是一款独立的两层电路板，搭载完整的 MCU 系统，安装在基板之上：

| 参数 | 说明 |
|------|------|
| **数量** | 共 56 块 |
| **MCU** | STM32F302x8（Cortex-M4, 72MHz），每块一片 |
| **通道数** | 每块 16 个通道/端口 |
| **总端口** | 56 × 16 = 896 个 |
| **层数** | 2 层板 |
| **晶振** | 24MHz 外部晶振 |
| **CAN 收发器** | 外接 CAN 收发芯片，接入基板上的 CAN 总线 |
| **电源方案** | 5V → 3.3V，功率电感降压，钽电容滤波 |
| **终端电阻** | 120Ω CAN 终端匹配电阻，开关控制（位于总线两端节点） |
| **LED 指示** | PWM 控制 LED（10% 占空比起步） |
| **调试接口** | SWD 调试/下载接口 |
| **复位** | Boot0 复位电路 |
| **网络拓扑** | 56 节点多主 CAN 网络，其中一块为主节点 |

> 所有 56 块 PCB 运行同一份固件（`lamost_broad_MCU/`），通过 CAN 总线协议中的节点 ID 区分角色。主节点负责协调调度，各从节点响应指令。

小单元 PCB 参考设计（`小单元原理图设计+PCB.zip`）包含：
- 原理图（PDF）
- PCB 布局图（PDF + 仿真顶层/底层图）
- SMT 3D 渲染图（含标注）
- 实物照片（顶层/底层）
- 主体尺寸图
- 设计说明文档（docx）

### 分块插线板

用于连接各小单元 PCB 的接口模块（16 通道），3D 模型文件：
- `分块插线板_16.STEP` — 标准间距版本
- `分块插线板_16接头间距加大.STEP` — 加大接头间距版本

## 固件功能

固件工程 `lamost_broad_MCU/` 基于 STM32CubeMX + HAL 库，使用 CMake 构建，烧录至每一块小单元 PCB 上运行。

### 主要功能模块

| 模块 | 说明 |
|------|------|
| **CAN 通信** | FIFO0 中断收发，250kbps，Filter 全部接收模式，56 节点多主网络 |
| **LED 控制** | PWM 调光（10% 占空比起步），`just_led.c/h` 实现 |
| **DMA** | 数据搬移，用于 CAN 数据高效传输 |
| **UART** | printf 重定向，调试打印输出 |
| **TIM** | 定时器用于 PWM 生成和时序控制 |
| **GPIO** | 通用 IO 控制，CAN 引脚复用配置 |
| **中断** | CAN FIFO0 中断接收，接收值存储与处理 |
| **端口映射** | `pcb_1_map[16]` 等数组定义基板孔位到 PCB 端口的映射关系 |

### 关键引脚映射

| 功能 | 引脚 | 说明 |
|------|------|------|
| CAN TX | PA12 | GPIO_AF9_CAN 复用 |
| CAN RX | PA11 | GPIO_AF9_CAN 复用 |
| CAN_S | PB0 | CAN 收发器模式控制 |
| LED | PB1 | PWM 控制输出 |

### CAN 总线参数

- **波特率**：250 kbps
- **主频**：72MHz（24MHz 晶振 × PLL）
- **终端电阻**：120Ω，总线两端节点含开关控制（可切换），带丝印标注
- **CAN 接口**：CANH / CANL 配对（丝印方向已修正）
- **拓扑**：基板上绘制的线性总线，56 节点并联
- **Filter**：当前配置为全部接收（不过滤）

## 接口映射可视化工具

[Canvas/canvas.html](Canvas/canvas.html) 是一个基于 HTML5 Canvas 的交互式编辑器，用于可视化编辑基板孔位与小单元 PCB 端口之间的连接映射关系。

### 功能特性
- **双侧画布**：左侧显示基板阵列，右侧显示 PCB 端口阵列
- **双向连线**：点击左侧孔位 + 右侧端口即可建立映射关系
- **智能编号**：自动编号，支持拖拽连线
- **缩放平移**：双侧支持滚轮缩放与拖拽平移
- **导出功能**：
  - 导出 JSON 格式配置（`pcb_mapping_*.json`）
  - 导出 C 语言数组代码（`pcb_c_array.txt`），格式为 `pcb_N_map[16]`，可直接用于固件编译
- **当前状态**：52 块 PCB 已配置（`pcb_1_map` ~ `pcb_52_map`，每块 16 端口，共 832 端口），待更新至 56 块

### 使用方法
直接用浏览器打开 `Canvas/canvas.html`，可用 `📂 加载配置 JSON` 加载已有的映射关系文件。

## 快速开始

### 固件编译与烧录

```bash
cd lamost_broad_MCU
cmake --preset Debug
cmake --build build/Debug
# 使用 ST-Link / J-Link 逐块烧录至 56 块小单元 PCB
```

或使用 STM32CubeMX 打开 `lamost_broad_MCU.ioc` 进行配置和代码生成。

### 查看基板设计

使用立创EDA 或 EasyEDA 打开 `外接板20260402.eprj` 工程文件。

### 查看 3D 模型

- **SolidWorks**：打开 `just外接板/` 中的 `.SLDPRT` 文件或 `pcb_3d_model/3D_PCB2_2026-04-02.SLDASM` 装配体
- **通用查看器**：任意 STEP/STL 查看器可打开 `.step` / `.stl` 文件

### 接口映射编辑器

直接用浏览器打开 `Canvas/canvas.html`。
